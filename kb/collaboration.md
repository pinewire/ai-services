# Shared mailbox access

Requests for a shared mailbox must include the mailbox address, business
justification, and manager approval. Access is granted through the identity
admin console and normally becomes active within one business day.

# Calendar invitation missing

If a calendar invitation is missing, check the recipient's focused and other
inboxes and ask the organizer to resend it. If multiple recipients are
affected, collaboration support should inspect the mail routing trace.
