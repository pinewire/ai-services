# Payroll portal unavailable

Payroll portal errors during the monthly close should be reported to Finance
Systems with the employee count affected and the exact error text. Agents
should not ask employees to retry repeatedly because a failed submission can
create a duplicate payroll record.

# Expense invoice rejected

When an expense invoice is rejected, check that the cost center and receipt
are attached before resubmitting. If both are present, Finance Systems must
review the approval workflow; do not create a second invoice for the same
vendor.
